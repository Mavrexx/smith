# Smith iOS unsigned IPA build

This repository contains the native Smith iOS client and a GitHub Actions macOS build.

Open **Actions → Build unsigned Smith IPA → Run workflow**. When the run completes, download the **Smith-unsigned-ipa** artifact. The IPA is intentionally unsigned so it can be signed by your preferred sideloading tool.

No Apple, Smith Core, Google, signing, or sideload-provider credentials are stored here.
